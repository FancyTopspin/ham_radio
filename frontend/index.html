Ham Radio Exam Prep — FCC Amateur Radio License Study Platform

A modern, offline-first study platform to help you pass all three tiers of the US Federal Communications Commission (FCC) Amateur Radio Service exams: Technician Class (Element 2), General Class (Element 3), and Amateur Extra Class (Element 4).

Official Question Pools Included

  • Technician Class (Element 2): 35 questions per exam, 26/35 (74%) to pass, 412 questions in pool (2022–2026 cycle).
  • General Class (Element 3): 35 questions per exam, 26/35 (74%) to pass, 429 questions in pool (2023–2027 cycle).
  • Amateur Extra Class (Element 4): 50 questions per exam, 37/50 (74%) to pass, 618 questions in pool (2024–2028 cycle).

Study Modes & Features

Features structured syllabus lessons, passive study mode with pre-selected answers and full pedagogical explanations, interactive practice quizzes with smart option shuffling, Leitner spaced repetition with 7-day retention decay, official NCVEC blueprint mock exams, daily 5-question blitz challenges with streak flames, and a national community leaderboard.
